HTML TABLES
===========

HTML tables are used to display data in rows and columns.

IMPORTANT TABLE TAGS
--------------------

<table>  - Defines the table
<tr>     - Defines a table row
<th>     - Defines a table heading
<td>     - Defines table data/cell
<caption> - Defines the table title
<thead>  - Groups the header section
<tbody>  - Groups the main data
<tfoot>  - Groups the footer section


1. BASIC TABLE
--------------

Example:

<table>
    <tr>
        <th>Name</th>
        <th>Age</th>
        <th>City</th>
    </tr>

    <tr>
        <td>Anu</td>
        <td>20</td>
        <td>Bengaluru</td>
    </tr>

    <tr>
        <td>Rahul</td>
        <td>21</td>
        <td>Mysuru</td>
    </tr>
</table>


2. TABLE WITH BORDER
--------------------

<table border="1">
    <tr>
        <th>Name</th>
        <th>Age</th>
    </tr>

    <tr>
        <td>Anu</td>
        <td>20</td>
    </tr>

    <tr>
        <td>Rahul</td>
        <td>21</td>
    </tr>
</table>

Note:
In modern HTML, CSS is preferred for adding borders.


3. TABLE WITH CAPTION
---------------------

The <caption> tag is used to give a title to a table.

Example:

<table border="1">

    <caption>Student Details</caption>

    <tr>
        <th>Name</th>
        <th>Course</th>
    </tr>

    <tr>
        <td>Anu</td>
        <td>CSE</td>
    </tr>

</table>


4. COLSPAN
-----------

colspan is used to make a cell span across multiple columns.

Example:

<table border="1">

    <tr>
        <th colspan="3">Student Details</th>
    </tr>

    <tr>
        <th>Name</th>
        <th>Age</th>
        <th>Course</th>
    </tr>

    <tr>
        <td>Anu</td>
        <td>20</td>
        <td>CSE</td>
    </tr>

</table>

Here, colspan="3" means the heading occupies 3 columns.


5. ROWSPAN
-----------

rowspan is used to make a cell span across multiple rows.

Example:

<table border="1">

    <tr>
        <th>Name</th>
        <th rowspan="2">Course</th>
    </tr>

    <tr>
        <td>Anu</td>
    </tr>

</table>

Here, rowspan="2" means the cell occupies 2 rows.


6. THEAD, TBODY AND TFOOT
-------------------------

<thead>  - Contains table headings
<tbody>  - Contains the main table data
<tfoot>  - Contains the footer of the table

Example:

<table border="1">

    <thead>
        <tr>
            <th>Name</th>
            <th>Marks</th>
        </tr>
    </thead>

    <tbody>
        <tr>
            <td>Anu</td>
            <td>90</td>
        </tr>

        <tr>
            <td>Rahul</td>
            <td>85</td>
        </tr>
    </tbody>

    <tfoot>
        <tr>
            <td>Total Students</td>
            <td>2</td>
        </tr>
    </tfoot>

</table>


7. TABLE USING CSS
------------------

CSS can be used to style tables.

Example:

<style>

    table {
        border-collapse: collapse;
        width: 60%;
    }

    th, td {
        border: 1px solid black;
        padding: 10px;
        text-align: center;
    }

    th {
        background-color: lightgray;
    }

</style>

<table>

    <tr>
        <th>Name</th>
        <th>Age</th>
        <th>Course</th>
    </tr>

    <tr>
        <td>Anu</td>
        <td>20</td>
        <td>CSE</td>
    </tr>

    <tr>
        <td>Rahul</td>
        <td>21</td>
        <td>ECE</td>
    </tr>

</table>


IMPORTANT ATTRIBUTES
--------------------

colspan
    Combines multiple columns.

rowspan
    Combines multiple rows.

border
    Adds a border around the table.

width
    Sets the width of the table.

Note:
CSS is recommended for styling tables instead of using HTML
attributes such as border and width.


QUICK SUMMARY
-------------

<table>     -> Creates a table
<tr>        -> Creates a row
<th>        -> Creates a heading cell
<td>        -> Creates a data cell
<caption>   -> Adds a table title
<thead>     -> Table header section
<tbody>     -> Table body section
<tfoot>     -> Table footer section
colspan     -> Spans multiple columns
rowspan     -> Spans multiple rows
