HTML FORMS - NOTES
===================

1. What is an HTML Form?
------------------------
An HTML form is used to collect input and information from users.
Forms are commonly used for:
- Registration
- Login
- Search
- Feedback
- Contact forms
- Online orders

The main <form> element is used to create a form.

Basic syntax:

<form>
    <!-- form elements go here -->
</form>


2. The <form> Element
---------------------
The <form> element is the container for all form controls.

Important attributes:

action
------
Specifies where the form data should be sent.

Example:
<form action="/submit">

method
------
Specifies how the form data is sent.

Common methods:
- GET: Sends data through the URL. Suitable for non-sensitive data.
- POST: Sends data in the request body. Commonly used for submitting sensitive or large data.

Example:
<form action="/submit" method="post">


3. The <label> Element
----------------------
The <label> element provides a description for a form control.

Example:

<label for="name">Name:</label>
<input type="text" id="name" name="name">

The "for" attribute should match the id of the related input.


4. The <input> Element
----------------------
The <input> element is used to create different types of input fields.

Text:
<input type="text" name="username">

Password:
<input type="password" name="password">

Email:
<input type="email" name="email">

Number:
<input type="number" name="age">

Date:
<input type="date" name="dob">

Time:
<input type="time" name="time">

File:
<input type="file" name="file">

Telephone:
<input type="tel" name="phone">

URL:
<input type="url" name="website">

Search:
<input type="search" name="search">

Hidden:
<input type="hidden" name="user_id" value="101">


5. Radio Buttons
----------------
Radio buttons allow the user to select only one option from a group.

Example:

<input type="radio" id="male" name="gender" value="male">
<label for="male">Male</label>

<input type="radio" id="female" name="gender" value="female">
<label for="female">Female</label>

The radio buttons must have the same "name" attribute to form one group.


6. Checkboxes
-------------
Checkboxes allow the user to select one or more options.

Example:

<input type="checkbox" id="html" name="skill" value="html">
<label for="html">HTML</label>

<input type="checkbox" id="css" name="skill" value="css">
<label for="css">CSS</label>


7. Submit Button
----------------
A submit button sends the form data.

Example:

<input type="submit" value="Submit">

or:

<button type="submit">Submit</button>


8. Reset Button
---------------
A reset button clears the form and restores the default values.

Example:

<input type="reset" value="Reset">

or:

<button type="reset">Reset</button>


9. <textarea>
-------------
The <textarea> element is used for multi-line text input.

Example:

<label for="message">Message:</label>
<textarea id="message" name="message" rows="5" cols="30"></textarea>


10. <select> and <option>
-------------------------
The <select> element creates a drop-down list.

Example:

<label for="course">Choose a course:</label>
<select id="course" name="course">
    <option value="cse">Computer Science</option>
    <option value="ds">Data Science</option>
    <option value="ece">Electronics</option>
</select>


11. <fieldset> and <legend>
---------------------------
<fieldset> groups related form controls.

<legend> gives a title to the group.

Example:

<fieldset>
    <legend>Personal Information</legend>

    <label for="name">Name:</label>
    <input type="text" id="name" name="name">

    <label for="email">Email:</label>
    <input type="email" id="email" name="email">
</fieldset>


12. Important Input Attributes
------------------------------
name
----
Identifies the form field when the data is submitted.

id
--
Uniquely identifies an element and connects it with a <label>.

value
-----
Specifies the value submitted for an input.

placeholder
-----------
Displays a temporary hint inside an input field.

Example:
<input type="text" placeholder="Enter your name">

required
--------
Makes a field mandatory.

Example:
<input type="email" name="email" required>

readonly
--------
Prevents the user from changing the value.

disabled
--------
Disables the form control.

checked
-------
Pre-selects a checkbox or radio button.

Example:
<input type="checkbox" checked>

maxlength
---------
Sets the maximum number of characters.

Example:
<input type="text" maxlength="20">

min and max
-----------
Set minimum and maximum values for number/date inputs.

Example:
<input type="number" min="1" max="100">


13. Complete HTML Form Example
------------------------------

<!DOCTYPE html>
<html>
<head>
    <title>Registration Form</title>
</head>
<body>

<h1>Registration Form</h1>

<form action="/submit" method="post">

    <label for="name">Full Name:</label>
    <input type="text" id="name" name="name" placeholder="Enter your name" required>
    <br><br>

    <label for="email">Email:</label>
    <input type="email" id="email" name="email" placeholder="Enter your email" required>
    <br><br>

    <label for="password">Password:</label>
    <input type="password" id="password" name="password" required>
    <br><br>

    <label>Gender:</label>
    <input type="radio" id="male" name="gender" value="male">
    <label for="male">Male</label>

    <input type="radio" id="female" name="gender" value="female">
    <label for="female">Female</label>
    <br><br>

    <label>Skills:</label>
    <input type="checkbox" id="html" name="skill" value="html">
    <label for="html">HTML</label>

    <input type="checkbox" id="css" name="skill" value="css">
    <label for="css">CSS</label>

    <input type="checkbox" id="javascript" name="skill" value="javascript">
    <label for="javascript">JavaScript</label>
    <br><br>

    <label for="course">Course:</label>
    <select id="course" name="course">
        <option value="cse">Computer Science</option>
        <option value="ds">Data Science</option>
        <option value="ece">Electronics</option>
    </select>
    <br><br>

    <label for="message">Message:</label>
    <br>
    <textarea id="message" name="message" rows="5" cols="30"></textarea>
    <br><br>

    <input type="submit" value="Submit">
    <input type="reset" value="Reset">

</form>

</body>
</html>


14. Common Form Input Types
---------------------------
text       - Single-line text
password   - Password input
email      - Email address
number     - Numeric input
radio      - Select one option
checkbox   - Select multiple options
date       - Select a date
time       - Select a time
file       - Upload a file
tel        - Telephone number
url        - Website URL
search     - Search field
submit     - Submit the form
reset      - Reset the form
button     - General button


15. Important Points to Remember
--------------------------------
1. Use <form> to create a form.
2. Use <label> to describe form controls.
3. The "for" attribute of <label> should match the input's "id".
4. The "name" attribute is important when submitting form data.
5. Use method="get" for URL-based submissions and method="post" for data sent in the request body.
6. Use "required" for mandatory fields.
7. Use radio buttons when only one option should be selected.
8. Use checkboxes when multiple options can be selected.
9. Use <textarea> for multi-line input.
10. Use <select> and <option> to create drop-down lists.
